# Classificador de nível de herói

Exercício JavaScript com entrada pelo terminal.

Com Node.js 22 ou superior, execute `node index.js`. Execute `node --test` para validar os limites e entradas inválidas.

XP deve ser um inteiro não negativo. Ferro inclui 0 a 1000; Bronze, 1001 a 2000; Prata, 2001 a 5000; Ouro, 5001 a 7000; Platina, 7001 a 8000; Ascendente, 8001 a 9000; Imortal, 9001 a 10000; Radiante, acima de 10000.
